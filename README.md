# AVOL Client

Releases of AVOL Client: the launcher and in-game client for Minecraft: Java Edition, 1.8.9 to 26.3.

**[Download the newest version](https://github.com/ver4ks/avol-client/releases/latest/download/Avol-Setup.exe)** (Windows) · [All releases](https://github.com/ver4ks/avol-client/releases)

Each release has the installer, `Avol-Setup.exe`. Avol checks this page for a newer version and installs it from here.

Not an official Minecraft product. Not approved by or associated with Mojang or Microsoft.
